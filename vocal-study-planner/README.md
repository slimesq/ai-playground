# 声乐练习室

一个独立的声乐课程排期和学习记录项目，位于 `/root/ai-playground/vocal-study-planner/`。

入口：<http://39.97.44.190/vocal-study-planner/>。服务器根地址跳转到这个入口。

## 默认计划

内推班，四个阶段、74 个课题。从 2026-10-05 开始，每周三、周六学习，间隔约 3–4 天。每两个阶段之间安排连续 7 天休息，共 3 次；休息期间不排课程或练习。共 82 次学习安排，最后一次安排在 2027-08-07，计划截止 2027-08-09。

各阶段的学习期采用图片里的 2、2.5、2.5、2.5 个月；半个月按 15 天计算。休息另计，在原有阶段边界上逐段顺延一周，保留学习日、各阶段学习期长度及课程安排数量。休息从前一阶段结束后的次日开始，不强制对齐周一；周次仍按日历计算。额外 8 次安排用于技能课的重复学习，典礼、考试和作品展示仅安排一次。不设置或统计学习时长。

设置支持修改开始日期和每周学习日，也支持前三阶段的全能班：学习期 7 个月，阶段间休息 2 周，默认截止 2027-05-18。修改排期后保留以课程编号保存的进度和学习记录。

## 使用

- 下一次学习、阶段进度和课程目录合并在一个页面。阶段列表默认展开当前阶段，支持搜索和筛选。
- 课程目录直接按首次上课的周次分组，相邻周使用浅米色、灰蓝色标题和细侧线区分。每门课仅显示一次，跨周练习标注覆盖周次；旧周次链接仍能定位对应内容，不隐藏其他课程。
- 搜索覆盖当前方案的全部课程和学习笔记，支持阶段、状态筛选，并显示当前条件及清除入口。
- 已完成、学习中、未开始课程使用不同的图标、文字和底色。阶段进度始终按整个阶段统计，不随搜索或筛选改变分母。
- 在课程详情中添加本次学习记录，保存后输入框清空；“学习历程”保留每次内容及添加时间，按最新到最早显示，北京时间精确到秒。同样内容再次保存也是独立记录，搜索会覆盖全部历史。
- 原有单条笔记迁移为一条历史，标明“原有记录 · 最后更新时间”，保留原更新时间。升级前已被覆盖的笔记没有历史数据，无法还原。
- 添加记录不会自动完成课程；完成、取消完成、修改课名不会新增学习记录或改动已有记录时间。新增记录和完成状态支持撤销。页面不统计实际学习时长，原有分钟数据仍保留在备份与同步记录中。
- 页面顶部按课程顺序显示第一门未完成的课，完成后自动推进，取消完成后回退。原定日期仅作为参考。“定位下一课”和详情中的定位按钮会清除筛选、展开目标阶段并滚动到课程。
- 每门课保留阶段和课程序号，课程名称可以直接修改。
- 课程操作和弹窗使用统一的线性 SVG 图标，浏览器标签页提供 PNG、ICO 图标及根目录兼容入口。
- 计划设置与同步、备份合并在一个弹窗，数据工具按需展开；只有修改了有效排期才可保存。
- 每个浏览器获得独立同步码。在另一设备的“同步与备份”输入同一码，即可恢复同一份排期和记录。
- 本地保存、服务器同步和 JSON 导出备份同时提供。跨设备冲突会保留本地草稿和服务器记录，可查看差异并选择保留内容；选择本地内容时合并双方已有的学习历程，撤销不会覆盖其他设备的新记录。未编辑的课程详情自动跟随远端更新，已有草稿保留。
- 导出使用版本 2，包含完整学习历程和原时间；导入同时兼容版本 1 与版本 2。

## 开发和验证

Node.js 22.16 或更新版本。运行服务无需第三方运行时依赖；Playwright 仅用于浏览器回归。

```bash
npm install
npm start
```

默认监听 `127.0.0.1:3010`，开发数据库为 `data/vocal.db`。

```bash
npm run check
npm test
```

若环境没有 Chromium，可先运行 `npx playwright install chromium`。测试使用独立的临时数据库、随机端口和浏览器上下文。

`public/plan.js` 管理课程原文和日期生成；`public/app.js` 管理页面、记录和同步；`public/journal.js` 统一校验学习历程与迁移旧笔记；`public/app.css` 管理响应式布局；`server.js` 使用 Node HTTP 和 SQLite 提供静态页面与 API，`start.js` 是命令行和 PM2 共用的服务入口。

## 部署

```bash
bash scripts/deploy.sh
```

部署脚本使用此服务器现有的 Nginx 路径网关，创建 `vocal-study-planner` PM2 服务和独立的 Nginx 路径片段。持久数据库保存在 `/var/lib/vocal-study-planner/vocal.db`。

新增标签页图标地址时，先部署静态路由并确认返回 200，再更新 HTML 引用。Chromium 会缓存失败的图标请求，原地址恢复后也可能不再重试；发生这种情况时需要换用新的图标文件地址。

API：`GET api/health`、`GET api/state`、`POST api/sync`。状态接口要求 `X-Study-Key` 同步码，按同步码隔离课程记录。每个请求最多 10 门课，按实际 UTF-8 字节数分批，单次上限为 160 KiB；备份导入上限为 16 MiB。每条历史包含 `id`、`createdAt`、`note`，旧笔记另带 `legacy:true`；每条最多 4000 字，每课历史 JSON 上限 96 KiB。历史包含于版本校验，已有记录的原时间不能修改。旧客户端省略历史字段时会保留服务器已有历史。

状态返回各课程及排期的 `versions`；客户端提交待同步修改及 `expected` 基线，服务端在事务内校验全部基线，冲突时返回 409 和最新状态，整批不写入。离线修改及冲突保存在本地，未提交的课程不会被删除。旧客户端不带 `expected` 的请求仍兼容按更新时间合并。
