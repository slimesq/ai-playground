# 训练手记

蛋壳健康四门训练课的记录网站：颈肩康复（4 周）、步态纠正（4 周）、腰背康复（6 周）、膝盖康复（4 周）。按官方训练组和课节查看，不设置日历排期；训练组与单节课都可以反复打卡，每次保留实际记录时间和备注。

## 运行与检查

需要 Node.js 22.16 或更新版本。

```bash
npm ci
npm run check
npm start
```

打开 `http://127.0.0.1:3011`。自动化检查运行 `npm test`；浏览器测试前先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

浏览器首次使用会自动生成随机同步码，作为学习记录的独立命名空间。同一浏览器会记住这个码；切换设备时使用相同同步码，才能访问同一份记录。

每次打卡先写入本机 IndexedDB，再同步到服务器；离线记录会在联网后自动上传。多个标签页通过事务合并记录，网络重试不会重复新增同一笔打卡。同步码可在右上角设置中复制。

右上角设置的“文件备份”支持导出全部四门课程的 JSON 备份和合并导入。导入前显示记录数量，保留原记录 ID、练习时间、创建时间及备注；同一份备份重复导入不会增加打卡次数，已有同编号记录优先保留。导出为 v2，同时兼容原来的 v1 文件；旧文件中的待同步操作不重放。文件最大 16 MiB，离线导入也会先完整保存在本机，再按实际 UTF-8 字节数分批同步。

## 课程目录

`public/catalog.json` 来自 `/root/bilibili-course-catalogs/449106131/2026-10-16/` 的哔哩哔哩官方课程目录快照，共 1085 条，保留原始章节顺序和课节名称。腰背课官方目录为 38 个训练章节；膝盖课标称 185 课时，实际目录 258 条，均按实际目录保留。此项目不包含课程视频。

## 部署

服务器沿用已有 PM2 和 Nginx 路径网关。安装项目依赖后，以拥有 Nginx 配置权限的用户执行：

```bash
bash scripts/deploy.sh
```

脚本先检查代码，再启动独立进程 `rehab-study-tracker`，健康检查通过后配置 `/rehab-study-tracker/`。服务只监听 `127.0.0.1:3011`。Nginx 片段位于 `/etc/nginx/ai-playground-paths.d/rehab-study-tracker.conf`；配置检查失败会恢复原片段。

打卡数据保存到 SQLite。生产环境使用 `DATABASE_FILE=/var/lib/rehab-study-tracker/rehab.db`，由 PM2 配置指定。数据库、同步记录、依赖和日志不纳入 Git；备份数据时单独备份 SQLite 数据库。`POST api/checkins/import` 在当前同步码下导入一批完整记录，每批最多 100 条、96 KiB；每批先完成校验再事务写入。
